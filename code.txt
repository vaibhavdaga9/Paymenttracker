      'Called On', 'Next Call Date', 'Status', 'Manager',

      paymentSheet.getRange(1, 10).setValue('Customer ID').setFontWeight('bold').setBackground('#4a90d9').setFontColor('#ffffff');

      paymentSheet.getRange(1, 11).setValue('Alternate Mobile No.').setFontWeight('bold').setBackground('#4a90d9').setFontColor('#ffffff');
      log.push('✓ Added Alternate Mobile No. column (K)');

    lookupSheet.getRange(1, 1, 1, 8).setFontWeight('bold').setBackground('#e8f4fd');

function normalizeMobileNumber(mobile) {
  if (mobile === null || mobile === undefined) return '';
  var digits = String(mobile).replace(/\D/g, '');
  if (digits.length === 12 && digits.indexOf('91') === 0) {
    digits = digits.slice(2);
  }
  return digits.length === 10 ? digits : '';
}

function getLookupSheetForCustomerIds() {
  var ss = SpreadsheetApp.openById(SHEET_ID);
  var lookupSheet = ss.getSheetByName(LOOKUP_SHEET_NAME);
  if (!lookupSheet) {
    setupSheets();
    lookupSheet = ss.getSheetByName(LOOKUP_SHEET_NAME);
  }
  return lookupSheet;
}

function getCustomerIdMapFromLookup() {
  var lookupSheet = getLookupSheetForCustomerIds();
  var map = {};
  if (lookupSheet && lookupSheet.getLastRow() > 1) {
    var rows = lookupSheet.getRange(2, 7, lookupSheet.getLastRow() - 1, 2).getValues();
    rows.forEach(function(r) {
      var mobile = normalizeMobileNumber(r[0]);
      var customerId = r[1] ? String(r[1]).trim() : '';
      if (mobile && customerId) map[mobile] = customerId;
    });
  }

  try {
    var ss = SpreadsheetApp.openById(SHEET_ID);
    var paymentSheet = ss.getSheetByName(DATA_SHEET_NAME);
    if (paymentSheet && paymentSheet.getLastRow() > 1) {
      var paymentRows = paymentSheet.getRange(2, 1, paymentSheet.getLastRow() - 1, PAYMENT_TOTAL_COLUMNS).getValues();
      paymentRows.forEach(function(r) {
        var mobile = normalizeMobileNumber(r[COL_MOBILE - 1]);
        var customerId = r[COL_CUSTOMER_ID - 1] ? String(r[COL_CUSTOMER_ID - 1]).trim() : '';
        if (mobile && customerId && !map[mobile]) map[mobile] = customerId;
      });
    }
  } catch (e) {
    Logger.log('Lookup map seed from payments failed: ' + e.message);
  }
  return map;
}

function getNextCustomerId(existingMap) {
  var maxNum = 0;
  Object.keys(existingMap || {}).forEach(function(mobile) {
    var id = existingMap[mobile];
    var m = String(id || '').match(/^CUS(\d{4,})$/i);
    if (m) {
      var n = Number(m[1]) || 0;
      if (n > maxNum) maxNum = n;
    }
  });
  return 'CUS' + String(maxNum + 1).padStart(4, '0');
}

function getOrCreateCustomerIdByMobile(mobile) {
  var normalized = normalizeMobileNumber(mobile);
  if (!normalized) return '';

  var lookupSheet = getLookupSheetForCustomerIds();
  var map = getCustomerIdMapFromLookup();
  if (map[normalized]) {
    if (lookupSheet && lookupSheet.getLastRow() > 1) {
      var rows = lookupSheet.getRange(2, 7, lookupSheet.getLastRow() - 1, 2).getValues();
      var existsInLookup = false;
      for (var i = 0; i < rows.length; i++) {
        if (normalizeMobileNumber(rows[i][0]) === normalized) {
          existsInLookup = true;
          break;
        }
      }
      if (!existsInLookup) {
        lookupSheet.appendRow(['', '', '', '', '', '', normalized, map[normalized]]);
      }
    } else if (lookupSheet) {
      lookupSheet.appendRow(['', '', '', '', '', '', normalized, map[normalized]]);
    }
    return map[normalized];
  }

  var newId = getNextCustomerId(map);
  lookupSheet.appendRow(['', '', '', '', '', '', normalized, newId]);
  return newId;
}

function ensureCustomerIdsForExistingRows() {
  try {
    var ss = SpreadsheetApp.openById(SHEET_ID);
    var sheet = ss.getSheetByName(DATA_SHEET_NAME);
    if (!sheet || sheet.getLastRow() <= 1) return;

    var data = sheet.getRange(2, 1, sheet.getLastRow() - 1, PAYMENT_TOTAL_COLUMNS).getValues();
    var updates = [];
    data.forEach(function(row, idx) {
      var mobile = normalizeMobileNumber(row[COL_MOBILE - 1]);
      if (!mobile) return;
      var currentId = row[COL_CUSTOMER_ID - 1] ? String(row[COL_CUSTOMER_ID - 1]).trim() : '';
      if (currentId) return;
      var customerId = getOrCreateCustomerIdByMobile(mobile);
      if (customerId) updates.push({ rowIndex: idx + 2, customerId: customerId });
    });

    updates.forEach(function(u) {
      sheet.getRange(u.rowIndex, COL_MOBILE).setValue(normalizeMobileNumber(sheet.getRange(u.rowIndex, COL_MOBILE).getValue()));
      sheet.getRange(u.rowIndex, COL_CUSTOMER_ID).setValue(u.customerId);
    });
  } catch (e) {
    Logger.log('ensureCustomerIdsForExistingRows error: ' + e.message);
  }
}

// DAYBOOK IMPORT: Parse and filter Tally daybook
// ============================================================
function parseDaybookData(base64FileData, fileName) {
  try {
    var bytes = Utilities.base64Decode(base64FileData);
    var isXlsx = bytes.length >= 4 &&
                 bytes[0] === 0x50 && bytes[1] === 0x4B &&
                 bytes[2] === 0x03 && bytes[3] === 0x04;

    var data;
    var tempFileId = null;

    if (isXlsx) {
      var xlsxBlob = Utilities.newBlob(
        bytes,
        'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet',
        'temp_daybook_' + new Date().getTime() + '.xlsx'
      );

      var tempFile = Drive.Files.insert(
        {
          title: 'temp_daybook_' + new Date().getTime(),
          mimeType: MimeType.GOOGLE_SHEETS
        },
        xlsxBlob,
        { convert: true }
      );
      tempFileId = tempFile.id;

      var ss = SpreadsheetApp.openById(tempFileId);
      var sheet = ss.getSheets()[0];
      data = sheet.getDataRange().getValues();

      try { DriveApp.getFileById(tempFileId).setTrashed(true); } catch (eCleanup) {}
    } else {
      var csvText = Utilities.newBlob(bytes).getDataAsString();
      data = Utilities.parseCsv(csvText);
    }
    
    var headerRowIdx = -1;
    for (var i = 0; i < data.length; i++) {
      var row = data[i];
      var a = row[0] ? String(row[0]).toLowerCase() : '';
      var b = row[1] ? String(row[1]).toLowerCase() : '';
      if (a.indexOf('date') > -1 && b.indexOf('particular') > -1) {
        headerRowIdx = i;
        break;
      }
    }

    if (headerRowIdx === -1) {
      return { success: false, error: 'Could not find header row. Ensure file has columns: Date, Particulars, Vch Type, Vch No., Debit Amount, Credit Amount' };
    }

    var filtered = [];

    for (var i = headerRowIdx + 2; i < data.length; i++) {
      var row = data[i];

      var dateRaw = row[0];
      var invoiceDate = '';
      if (dateRaw) {
        if (typeof dateRaw === 'object' && dateRaw instanceof Date) {
          invoiceDate = Utilities.formatDate(dateRaw, Session.getScriptTimeZone(), 'yyyy-MM-dd');
        } else {
          var parsed = new Date(dateRaw);
          if (!isNaN(parsed.getTime())) {
            invoiceDate = Utilities.formatDate(parsed, Session.getScriptTimeZone(), 'yyyy-MM-dd');
          }
        }
      }
      if (!invoiceDate) continue;

      var partyName = row[1] ? String(row[1]).trim() : '';
      if (!partyName) continue;

      var vchType = row[2] ? String(row[2]).trim() : '';

      var invoiceNo = row[3] ? String(row[3]).trim() : '';
      if (!invoiceNo) continue;

      var amount = row[4] ? Number(row[4]) : 0;
      if (!amount || amount <= 0) continue;

      filtered.push({
        invoiceDate: invoiceDate,
        partyName: partyName,
        invoiceNo: invoiceNo,
        amount: amount,
        voucherType: vchType
      });
    }

    if (filtered.length === 0) {
      return { success: false, error: 'No valid invoices found. Each data row must have Date (A), Client Name (B), Invoice No. (D), and Amount (E) > 0.' };
    }

    return { success: true, invoices: filtered, count: filtered.length };
  } catch (e) {
    return { success: false, error: 'Error parsing file: ' + e.message };
  }
}

// DAYBOOK IMPORT: Get preview
// ============================================================
function getDaybookPreview(base64FileData) {
  try {
    var parseResult = parseDaybookData(base64FileData, '');
    if (!parseResult.success) {
      return { success: false, error: parseResult.error };
    }

    var invoices = parseResult.invoices || [];

    // Build client → {manager, mobile} map from existing Payments rows so the
    // preview can prefill mobile + apply manager-based default days.
    // Also build a set of ALL existing invoice numbers (extracted from Remarks)
    // so we can flag duplicates before import.
    var existingInfoByClient = {};
    var existingInvoiceNos = {}; // set-like map { "INV001": true }
    try {
      var ss = SpreadsheetApp.openById(SHEET_ID);
      var pSheet = ss.getSheetByName(DATA_SHEET_NAME);
      if (pSheet && pSheet.getLastRow() > 1) {
        // Cols 2..9 = B..I → 8 cols. index 0 = Client, index 1 = Mobile, index 3 = Remarks, index 7 = Manager
        var rows = pSheet.getRange(2, 2, pSheet.getLastRow() - 1, 8).getValues();
        rows.forEach(function(r) {
          var nm = r[0] ? String(r[0]).trim().toUpperCase() : '';
          if (!nm) return;
          var mob = r[1] ? String(r[1]).trim() : '';
          var remarks = r[3] ? String(r[3]) : '';
          var mgr = r[7] ? String(r[7]).trim() : '';
          if (!existingInfoByClient[nm]) existingInfoByClient[nm] = { manager: '', mobile: '' };
          if (mgr && !existingInfoByClient[nm].manager) existingInfoByClient[nm].manager = mgr;
          if (mob && !existingInfoByClient[nm].mobile) existingInfoByClient[nm].mobile = mob;
          // Extract invoice numbers from the Remarks field (format: "Invoices: A, B, C (TAX)")
          extractInvoiceNos(remarks).forEach(function(no) {
            existingInvoiceNos[no.toUpperCase()] = true;
          });
        });
      }
    } catch (eLookup) { /* silent */ }

    var preview = [];
    var totalAmount = 0;
    var duplicateCount = 0;

    invoices.forEach(function(inv) {
      var key = String(inv.partyName || '').trim().toUpperCase();
      var info = existingInfoByClient[key] || { manager: '', mobile: '' };
      var mUpper = info.manager.toUpperCase();
      var paymentDays = (mUpper === 'VIPUL' || mUpper === 'SHRAVAN') ? 15 : 30;

      var invoiceDate = new Date(inv.invoiceDate);
      var nextCallDate = new Date(invoiceDate);
      nextCallDate.setDate(nextCallDate.getDate() + paymentDays);
      var nextCallStr = Utilities.formatDate(nextCallDate, Session.getScriptTimeZone(), 'yyyy-MM-dd');

      var invNoKey = String(inv.invoiceNo || '').trim().toUpperCase();
      var isDup = invNoKey && existingInvoiceNos[invNoKey] === true;
      if (isDup) duplicateCount++;

      preview.push({
        invoiceDate: inv.invoiceDate,
        partyName: inv.partyName,
        invoiceNo: inv.invoiceNo,
        amount: inv.amount,
        voucherType: inv.voucherType,
        mobile: info.mobile,
        manager: info.manager,
        paymentDays: paymentDays,
        nextCallDate: nextCallStr,
        isDuplicate: isDup
      });

      totalAmount += inv.amount;
    });

    return {
      success: true,
      invoices: preview,
      totalInvoices: preview.length,
      totalAmount: totalAmount,
      duplicateCount: duplicateCount,
      managers: getManagers()   // supply managers list so preview UI can render the Manager dropdown
    };
  } catch (e) {
    return { success: false, error: 'Error: ' + e.message };
  }
}

// ============================================================
// Helper: parse invoice numbers out of a Remarks string
// Expected format: "Invoices: INV001, INV002, INV003 (TAX INVOICE)"
// ============================================================
function extractInvoiceNos(remarks) {
  if (!remarks) return [];
  var s = String(remarks);
  var m = s.match(/Invoices?\s*:\s*([^(]+)/i);
  if (!m) return [];
  return m[1].split(',').map(function(x) { return x.trim(); }).filter(function(x) { return x; });
}

// DAYBOOK IMPORT: Import invoices
// ============================================================
function importDaybookInvoices(base64FileData) {
  try {
    var parseResult = parseDaybookData(base64FileData, '');
    if (!parseResult.success) {
      return { success: false, error: parseResult.error };
    }
    
    var invoices = parseResult.invoices || [];
    var ss = SpreadsheetApp.openById(SHEET_ID);
    var paymentSheet = ss.getSheetByName(DATA_SHEET_NAME);
    
    var imported = 0;
    var errors = [];
    
    invoices.forEach(function(inv) {
      try {
        var paymentDays = 30;
        
        var invoiceDate = new Date(inv.invoiceDate);
        var nextCallDate = new Date(invoiceDate);
        nextCallDate.setDate(nextCallDate.getDate() + paymentDays);
        var nextCallStr = Utilities.formatDate(nextCallDate, Session.getScriptTimeZone(), 'yyyy-MM-dd');
        
        var mobile = normalizeMobileNumber(inv.mobile || '');
        var customerId = mobile ? getOrCreateCustomerIdByMobile(mobile) : '';

        // 11-col layout: Date | Client | Mobile | Amount | Remarks | Called On | Next Call | Status | Manager | Customer ID | Alternate Mobile
        paymentSheet.appendRow([
          inv.invoiceDate,
          inv.partyName,
          mobile,
          inv.amount,
          'Invoice: ' + inv.invoiceNo + ' (' + inv.voucherType + ')',
          inv.invoiceDate,
          nextCallStr,
          'Pending',
          '',
          customerId,
          ''
        ]);
        
        imported++;
      } catch (e) {
        errors.push(inv.invoiceNo + ': ' + e.message);
      }
    });
    
    return {
      success: true,
      message: 'Imported ' + imported + ' invoices successfully!',
      imported: imported,
      total: invoices.length,
      errors: errors
    };
  } catch (e) {
    return { success: false, error: 'Import error: ' + e.message };
  }
}

// DAYBOOK IMPORT: Save grouped/edited preview
// ============================================================
function importDaybookGrouped(groupedInvoices) {
  try {
    if (!groupedInvoices || !groupedInvoices.length) {
      return { success: false, error: 'No invoices to import.' };
    }
    var ss = SpreadsheetApp.openById(SHEET_ID);
    var paymentSheet = ss.getSheetByName(DATA_SHEET_NAME);
    if (!paymentSheet) {
      setupSheets();
      paymentSheet = ss.getSheetByName(DATA_SHEET_NAME);
    }
    
    var imported = 0;
    var errors = [];

    // Build a client → manager map from existing rows so newly imported invoices
    // for the SAME client automatically inherit the manager already assigned.
    // Also build a set of ALL existing invoice numbers so we skip duplicates.
    // Sheet layout: Client=col 2, Manager=col 9. Read cols 2..9 (8 columns).
    var existingMgrByClient = {};
    var existingInvoiceNos = {};
    if (paymentSheet.getLastRow() > 1) {
      var existing = paymentSheet.getRange(2, 2, paymentSheet.getLastRow() - 1, 8).getValues();
      // Within this slice: index 0 = Client, index 3 = Remarks, index 7 = Manager
      existing.forEach(function(r) {
        var nm = r[0] ? String(r[0]).trim().toUpperCase() : '';
        var mgr = r[7] ? String(r[7]).trim() : '';
        if (nm && mgr && !existingMgrByClient[nm]) existingMgrByClient[nm] = mgr;
        var rem = r[3] ? String(r[3]) : '';
        extractInvoiceNos(rem).forEach(function(no) {
          existingInvoiceNos[no.toUpperCase()] = true;
        });
      });
    }

    var duplicatesSkipped = [];

    groupedInvoices.forEach(function(g) {
      try {
        var partyName = String(g.partyName || '').trim();
        if (!partyName) { errors.push('Skipped: empty party name'); return; }

        // Mobile: prefer what user typed/edited in preview, else auto-inherit from existing rows for this client
        var mobile = normalizeMobileNumber((g.mobile && String(g.mobile).trim()) || '');
        var customerId = mobile ? getOrCreateCustomerIdByMobile(mobile) : '';

        // Manager: prefer user's selection from preview dropdown; else auto-inherit existing assignment for this client
        var chosenMgr = (g.manager && String(g.manager).trim()) || '';
        var inheritedMgr = chosenMgr || existingMgrByClient[partyName.toUpperCase()] || '';

        var mgrKey = inheritedMgr.toUpperCase();
        var isShortCycleMgr = (mgrKey === 'VIPUL' || mgrKey === 'SHRAVAN');
        var paymentDays = Number(g.paymentDays);
        if (!paymentDays || paymentDays < 1) paymentDays = isShortCycleMgr ? 15 : 30;
        else if (isShortCycleMgr && paymentDays === 30) paymentDays = 15;

        // ============================================================
        // Each invoice becomes its OWN row in Records (no grouping)
        // Uses g.invoices (array of {invoiceNo, amount, invoiceDate, voucherType})
        // Falls back to synthesized data from legacy g.invoiceNos if array missing.
        // ============================================================
        var invoicesList = (g.invoices && g.invoices.length) ? g.invoices : (
          (g.invoiceNos || []).map(function(no) {
            return {
              invoiceNo: no,
              amount: (Number(g.totalAmount) / (g.invoiceNos.length || 1)) || 0,
              invoiceDate: g.invoiceDate,
              voucherType: (g.voucherTypes && g.voucherTypes[0]) || ''
            };
          })
        );

        invoicesList.forEach(function(inv) {
          var invNoKey = String(inv.invoiceNo || '').trim().toUpperCase();
          if (invNoKey && existingInvoiceNos[invNoKey]) {
            duplicatesSkipped.push({ partyName: partyName, invoiceNos: [inv.invoiceNo] });
            return;
          }

          // Prefer per-invoice partyName if provided by frontend (defensive: prevents
          // a grouping mismatch from writing the wrong name against an amount).
          var rowPartyName = (inv.partyName && String(inv.partyName).trim()) || partyName;

          var invDate = new Date(inv.invoiceDate || g.invoiceDate);
          if (isNaN(invDate.getTime())) invDate = new Date();
          var invDateStr = Utilities.formatDate(invDate, Session.getScriptTimeZone(), 'yyyy-MM-dd');

          var nextCallDate = new Date(invDate);
          nextCallDate.setDate(nextCallDate.getDate() + paymentDays);
          var nextCallStr = Utilities.formatDate(nextCallDate, Session.getScriptTimeZone(), 'yyyy-MM-dd');

          var vchType = inv.voucherType || (g.voucherTypes && g.voucherTypes[0]) || '';
          var remarks = 'Invoice: ' + (inv.invoiceNo || '-') + (vchType ? ' (' + vchType + ')' : '');

          // 11-col layout: Date | Client | Mobile | Amount | Remarks | Called On | Next Call | Status | Manager | Customer ID | Alternate Mobile
          paymentSheet.appendRow([
            invDateStr,
            rowPartyName,
            mobile,
            Number(inv.amount) || 0,
            remarks,
            invDateStr,
            nextCallStr,
            'Pending',
            inheritedMgr,
            customerId,
            ''
          ]);

          if (invNoKey) existingInvoiceNos[invNoKey] = true;
          imported++;
        });
      } catch (e) {
        errors.push((g && g.partyName ? g.partyName : 'row') + ': ' + e.message);
      }
    });

    return {
      success: true,
      message: 'Imported ' + imported + ' customers successfully!' + (duplicatesSkipped.length > 0 ? ' (' + duplicatesSkipped.length + ' duplicate group(s) skipped or trimmed)' : ''),
      imported: imported,
      total: groupedInvoices.length,
      errors: errors,
      duplicatesSkipped: duplicatesSkipped
    };
  } catch (e) {
    return { success: false, error: 'Import error: ' + e.message };
  }
}

// ============================================================
// RECEIPT IMPORT: Parse receipts
// ============================================================
function parseReceiptData(base64FileData) {
  try {
    var bytes = Utilities.base64Decode(base64FileData);
    var isXlsx = bytes.length >= 4 &&
                 bytes[0] === 0x50 && bytes[1] === 0x4B &&
                 bytes[2] === 0x03 && bytes[3] === 0x04;
    var data;
    var tempFileId = null;

    if (isXlsx) {
      var xlsxBlob = Utilities.newBlob(
        bytes,
        'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet',
        'temp_receipt_' + new Date().getTime() + '.xlsx'
      );
      var tempFile = Drive.Files.insert(
        { title: 'temp_receipt_' + new Date().getTime(), mimeType: MimeType.GOOGLE_SHEETS },
        xlsxBlob,
        { convert: true }
      );
      tempFileId = tempFile.id;
      var ss = SpreadsheetApp.openById(tempFileId);
      var sheet = ss.getSheets()[0];
      data = sheet.getDataRange().getValues();
      try { DriveApp.getFileById(tempFileId).setTrashed(true); } catch (eCleanup) {}
    } else {
      var csvText = Utilities.newBlob(bytes).getDataAsString();
      data = Utilities.parseCsv(csvText);
    }

    var headerRowIdx = -1;
    for (var i = 0; i < data.length; i++) {
      var a = data[i][0] ? String(data[i][0]).toLowerCase() : '';
      var b = data[i][1] ? String(data[i][1]).toLowerCase() : '';
      if (a.indexOf('date') > -1 && b.indexOf('particular') > -1) {
        headerRowIdx = i;
        break;
      }
    }
    if (headerRowIdx === -1) {
      return { success: false, error: 'Could not find header row. Receipt file must have columns: Date, Particulars, Vch Type, Vch No., Debit, Credit.' };
    }

    var receipts = [];
    for (var i = headerRowIdx + 2; i < data.length; i++) {
      var row = data[i];

      var dRaw = row[0];
      var rDate = '';
      if (dRaw) {
        if (typeof dRaw === 'object' && dRaw instanceof Date) {
          rDate = Utilities.formatDate(dRaw, Session.getScriptTimeZone(), 'yyyy-MM-dd');
        } else {
          var p = new Date(dRaw);
          if (!isNaN(p.getTime())) {
            rDate = Utilities.formatDate(p, Session.getScriptTimeZone(), 'yyyy-MM-dd');
          }
        }
      }
      if (!rDate) continue;

      var clientName = row[1] ? String(row[1]).trim() : '';
      if (!clientName) continue;

      var amount = row[5] ? Number(row[5]) : 0;
      if (!amount || amount <= 0) continue;

      receipts.push({ receiptDate: rDate, clientName: clientName, amount: amount });
    }

    if (receipts.length === 0) {
      return { success: false, error: 'No valid receipt rows found. Each row must have Date (A), Client Name (B), and Credit Amount (F) > 0.' };
    }
    return { success: true, receipts: receipts };
  } catch (e) {
    return { success: false, error: 'Error parsing receipt file: ' + e.message };
  }
}

// ============================================================
// RECEIPT IMPORT: Get preview
// ============================================================
function getReceiptPreview(base64FileData) {
  try {
    var parsed = parseReceiptData(base64FileData);
    if (!parsed.success) return { success: false, error: parsed.error };

    var receipts = parsed.receipts;

    var byClient = {};
    receipts.forEach(function(r) {
      var key = r.clientName.toUpperCase();
      if (!byClient[key]) {
        byClient[key] = {
          clientName: r.clientName,
          totalReceived: 0,
          latestReceiptDate: r.receiptDate,
          rawReceipts: []
        };
      }
      byClient[key].totalReceived += r.amount;
      byClient[key].rawReceipts.push(r);
      if (new Date(r.receiptDate) > new Date(byClient[key].latestReceiptDate)) {
        byClient[key].latestReceiptDate = r.receiptDate;
      }
    });

    var ss = SpreadsheetApp.openById(SHEET_ID);
    var sheet = ss.getSheetByName(DATA_SHEET_NAME);
    var pendingByClient = {};
    if (sheet && sheet.getLastRow() > 1) {
      // Payments sheet columns: A..K
      var allRows = sheet.getRange(2, 1, sheet.getLastRow() - 1, PAYMENT_TOTAL_COLUMNS).getValues();
      allRows.forEach(function(r, idx) {
        var status = r[7] ? String(r[7]).trim().toLowerCase() : '';
        if (status === 'received') return;
        var name = r[1] ? String(r[1]).trim() : '';
        if (!name) return;
        var amt = Number(r[3]) || 0;
        if (amt <= 0) return;
        var key = name.toUpperCase();
        if (!pendingByClient[key]) pendingByClient[key] = { totalPending: 0, billCount: 0, rowIndices: [], bills: [] };
        pendingByClient[key].totalPending += amt;
        pendingByClient[key].billCount += 1;
        pendingByClient[key].rowIndices.push(idx + 2);
        pendingByClient[key].bills.push({
          rowIndex: idx + 2,
          clientName: name,
          amount: amt,
          invoiceDate: r[0] ? Utilities.formatDate(new Date(r[0]), Session.getScriptTimeZone(), 'yyyy-MM-dd') : '',
          nextCallDate: r[6] ? Utilities.formatDate(new Date(r[6]), Session.getScriptTimeZone(), 'yyyy-MM-dd') : '',
          remarks: r[4] || ''
        });
      });
    }

    var preview = Object.keys(byClient).map(function(key) {
      var rcpt = byClient[key];
      var pend = pendingByClient[key];
      var pendingTotal = pend ? pend.totalPending : 0;
      var billCount = pend ? pend.billCount : 0;
      var rowIndices = pend ? pend.rowIndices : [];
      var bills = pend ? pend.bills : [];

      var matched = (billCount > 0) && (Math.round(rcpt.totalReceived * 100) === Math.round(pendingTotal * 100));
      var reason;
      if (billCount === 0) reason = 'no_bills';
      else if (matched) reason = 'matched';
      else if (rcpt.totalReceived < pendingTotal) reason = 'short';
      else reason = 'excess';

      return {
        clientName: rcpt.clientName,
        receiptAmount: rcpt.totalReceived,
        receiptDate: rcpt.latestReceiptDate,
        receiptCount: rcpt.rawReceipts.length,
        pendingTotal: pendingTotal,
        billCount: billCount,
        rowIndices: rowIndices,
        bills: bills,
        matched: matched,
        reason: reason
      };
    });

    var order = { matched: 0, short: 1, excess: 2, no_bills: 3 };
    preview.sort(function(a, b) { return order[a.reason] - order[b.reason]; });

    var matchedCount = preview.filter(function(p) { return p.matched; }).length;
    var matchedAmount = preview.filter(function(p) { return p.matched; })
                               .reduce(function(s, p) { return s + p.receiptAmount; }, 0);

    return {
      success: true,
      groups: preview,
      totalGroups: preview.length,
      matchedCount: matchedCount,
      matchedAmount: matchedAmount,
      totalReceiptAmount: preview.reduce(function(s, p) { return s + p.receiptAmount; }, 0)
    };
  } catch (e) {
    return { success: false, error: 'Error: ' + e.message };
  }
}

// RECEIPT IMPORT: Process matched groups
// ============================================================
function importReceiptMatches(matchedGroups) {
  try {
    if (!matchedGroups || !matchedGroups.length) {
      return { success: false, error: 'No matched groups to import.' };
    }
    var ss = SpreadsheetApp.openById(SHEET_ID);
    var sheet = ss.getSheetByName(DATA_SHEET_NAME);
    if (!sheet) return { success: false, error: 'Payments sheet not found.' };

    var toDelete = [];
    matchedGroups.forEach(function(g) {
      if (!g.matched) return;
      (g.rowIndices || []).forEach(function(rIdx) {
        toDelete.push({ rowIndex: rIdx, clientName: g.clientName, receiptDate: g.receiptDate });
      });
    });
    if (toDelete.length === 0) {
      return { success: false, error: 'No rows selected for received-import.' };
    }

    toDelete.sort(function(a, b) { return b.rowIndex - a.rowIndex; });
    var deleted = 0;
    toDelete.forEach(function(t) {
      try { sheet.deleteRow(t.rowIndex); deleted++; } catch (eDel) {}
    });

    return {
      success: true,
      imported: deleted,
      clientsCleared: matchedGroups.filter(function(g) { return g.matched; }).length,
      message: 'Marked ' + deleted + ' invoice(s) across ' + matchedGroups.filter(function(g) { return g.matched; }).length + ' customer(s) as Received.'
    };
  } catch (e) {
    return { success: false, error: 'Error: ' + e.message };
  }
}

// SCHEDULE: Group pending payments by Next Call Date
// ============================================================
function getReceivableByDate() {
  try {
    var ss = SpreadsheetApp.openById(SHEET_ID);
    var sheet = ss.getSheetByName(DATA_SHEET_NAME);
    if (!sheet || sheet.getLastRow() <= 1) return [];

    var data = sheet.getRange(2, 1, sheet.getLastRow() - 1, PAYMENT_TOTAL_COLUMNS).getValues();
    var groups = {};
    var today = new Date();
    today.setHours(0, 0, 0, 0);

    data.forEach(function(row, idx) {
      var status = row[7] ? String(row[7]).trim().toLowerCase() : '';
      if (status === 'received') return;
      if (!row[6]) return;
      var ncd = new Date(row[6]);
      if (isNaN(ncd.getTime())) return;
      var key = Utilities.formatDate(ncd, Session.getScriptTimeZone(), 'yyyy-MM-dd');
      var ncdNoTime = new Date(ncd.getFullYear(), ncd.getMonth(), ncd.getDate());
      var daysFromToday = Math.round((ncdNoTime.getTime() - today.getTime()) / 86400000);
      var daysOverdue = daysFromToday < 0 ? Math.abs(daysFromToday) : 0;
      
      if (!groups[key]) {
        groups[key] = { invoiceDate: row[0] ? Utilities.formatDate(new Date(row[0]), Session.getScriptTimeZone(), 'yyyy-MM-dd') : '', date: key, count: 0, totalAmount: 0, daysFromToday: daysFromToday, daysOverdue: daysOverdue, customers: [] };
      }
      var amt = Number(row[3]) || 0;
      groups[key].count++;
      groups[key].totalAmount += amt;
      groups[key].customers.push({
        rowIndex: idx + 2,           // real sheet row number (header at row 1)
        clientName: row[1] || '',
        amount: amt,
        mobile: row[2] || '',
        remarks: row[4] || ''
      });
    });

    var arr = Object.keys(groups).map(function(k) { return groups[k]; });
    arr.sort(function(a, b) { return new Date(a.date) - new Date(b.date); });
    return arr;
  } catch (e) {
    return [];
  }
}

// DAILY REMINDER: Send email with overdue + today's payment list
// ============================================================
function sendWhatsAppReminder() {
  var ss = SpreadsheetApp.openById(SHEET_ID);
  var sheet = ss.getSheetByName(DATA_SHEET_NAME);
  if (!sheet || sheet.getLastRow() <= 1) {
    Logger.log('No payments sheet or empty.');
    return;
  }

  var today = new Date();
  var todayMidnight = new Date(today.getFullYear(), today.getMonth(), today.getDate());
  var todayStr = Utilities.formatDate(today, Session.getScriptTimeZone(), 'yyyy-MM-dd');

  var data = sheet.getRange(2, 1, sheet.getLastRow() - 1, PAYMENT_TOTAL_COLUMNS).getValues();
  var overdueByClient = {};
  var dueTodayByClient = {};

  data.forEach(function(row) {
    if (!row[6]) return; // no Next Call Date
    var statusRaw = row[7] ? String(row[7]).trim().toLowerCase() : '';
    if (statusRaw === 'received') return;

    var ncd = new Date(row[6]);
    if (isNaN(ncd.getTime())) return;
    var ncdMidnight = new Date(ncd.getFullYear(), ncd.getMonth(), ncd.getDate());
    var ncdStr = Utilities.formatDate(ncd, Session.getScriptTimeZone(), 'yyyy-MM-dd');
    var client = row[1] ? String(row[1]).trim() : '';
    if (!client) return;
    var amount = Number(row[3]) || 0;
    if (amount <= 0) return;
    var key = client.toUpperCase();

    if (ncdMidnight.getTime() < todayMidnight.getTime()) {
      if (!overdueByClient[key]) overdueByClient[key] = { client: client, amount: 0 };
      overdueByClient[key].amount += amount;
    } else if (ncdStr === todayStr) {
      if (!dueTodayByClient[key]) dueTodayByClient[key] = { client: client, amount: 0 };
      dueTodayByClient[key].amount += amount;
    }
  });

  var overdue = Object.keys(overdueByClient).map(function(k) { return overdueByClient[k]; });
  var dueToday = Object.keys(dueTodayByClient).map(function(k) { return dueTodayByClient[k]; });
  var alphaSort = function(a, b) {
    return String(a.client || '').toUpperCase().localeCompare(String(b.client || '').toUpperCase());
  };
  overdue.sort(alphaSort);
  dueToday.sort(alphaSort);

  var formattedToday = Utilities.formatDate(today, Session.getScriptTimeZone(), 'dd MMM yyyy');
  var totalOverdueAmt = overdue.reduce(function(s, e) { return s + e.amount; }, 0);
  var totalDueTodayAmt = dueToday.reduce(function(s, e) { return s + e.amount; }, 0);
  var totalCount = overdue.length + dueToday.length;

  if (totalCount === 0) {
    var clearBody = '<!DOCTYPE html><html><body style="font-family:Arial,sans-serif;max-width:700px;">' +
      '<h2 style="color:#059669;">✅ No Overdue or Due-Today Payments</h2>' +
      '<p><strong>Date:</strong> ' + formattedToday + '</p>' +
      '<p>You are all caught up. No follow-up calls needed today. 🎉</p>' +
      '</body></html>';
    MailApp.sendEmail(
      MANAGER_EMAIL,
      '✅ All Clear — No Pending Payments — ' + formattedToday,
      'No overdue or due-today payments. You are all caught up.',
      { htmlBody: clearBody }
    );
    Logger.log('Sent "all clear" reminder for ' + todayStr);
    return;
  }

  var compactListHtml = function(title, items, color) {
    if (!items.length) return '';
    var rows = items.map(function(item) {
      return '<tr><td style="padding:6px 8px;border-bottom:1px solid #eee;">' + item.client + '</td><td style="padding:6px 8px;border-bottom:1px solid #eee;text-align:right;">₹' + formatINR(item.amount) + '</td></tr>';
    }).join('');
    return '<h3 style="margin:16px 0 8px;color:' + color + ';">' + title + ' (' + items.length + ')</h3>' +
      '<table style="width:100%;border-collapse:collapse;font-size:13px;"><thead><tr><th style="text-align:left;padding:6px 8px;background:#f9fafb;">Customer</th><th style="text-align:right;padding:6px 8px;background:#f9fafb;">Amount Due</th></tr></thead><tbody>' + rows + '</tbody></table>';
  };

  var emailBody = '<!DOCTYPE html><html><body style="font-family:Arial,sans-serif;max-width:720px;margin:0 auto;color:#1f2937;">' +
    '<h2 style="margin-bottom:6px;">📞 Daily Payment Summary</h2>' +
    '<p style="margin:0 0 10px;"><strong>Date:</strong> ' + formattedToday + '</p>' +
    '<p style="background:#f3f4f6;padding:10px;border-radius:6px;font-size:13px;">' +
      'Overdue: <strong>' + overdue.length + '</strong> (₹' + formatINR(totalOverdueAmt) + ') &nbsp;|&nbsp; ' +
      'Due Today: <strong>' + dueToday.length + '</strong> (₹' + formatINR(totalDueTodayAmt) + ') &nbsp;|&nbsp; ' +
      'Total: <strong>₹' + formatINR(totalOverdueAmt + totalDueTodayAmt) + '</strong>' +
    '</p>' +
    compactListHtml('🚨 Overdue', overdue, '#dc2626') +
    compactListHtml('📅 Due Today', dueToday, '#1d4ed8') +
    '<p style="font-size:11px;color:#6b7280;margin-top:12px;">Email trimmed to customer-wise totals for delivery reliability.</p>' +
    '</body></html>';

  var subject = '📞 ' + totalCount + ' Customer Due — ' + overdue.length + ' Overdue, ' + dueToday.length + ' Due Today — ' + formattedToday;

  MailApp.sendEmail(
    MANAGER_EMAIL,
    subject,
    'Daily Payment Summary: customer name and amount due.',
    { htmlBody: emailBody }
  );

  Logger.log('Compact reminder sent: ' + overdue.length + ' overdue clients, ' + dueToday.length + ' due-today clients.');
}

// Helper: build one manager's block (tables + subtotal + WA button)
// ============================================================
function buildManagerBlockHtml(name, mgrOverdue, mgrDueToday, mgrMobile, formattedToday) {
  var ovAmt = mgrOverdue.reduce(function(s, e) { return s + e.amount; }, 0);
  var dtAmt = mgrDueToday.reduce(function(s, e) { return s + e.amount; }, 0);
  var mgrTotal = ovAmt + dtAmt;
  var block = '<div class="s-mgr">' +
    '<div class="s-mgr-head">' +
      '<h3>👤 ' + name + '</h3>' +
      '<div class="s-badges">' +
        (mgrOverdue.length > 0 ? '<span class="s-bd-red">' + mgrOverdue.length + ' overdue (₹' + formatINR(ovAmt) + ')</span>' : '') +
        (mgrDueToday.length > 0 ? '<span class="s-bd-blue">' + mgrDueToday.length + ' due today (₹' + formatINR(dtAmt) + ')</span>' : '') +
        '<strong>Total: ₹' + formatINR(mgrTotal) + '</strong>' +
      '</div>' +
    '</div>';

  if (mgrOverdue.length > 0) {
    block += '<h3 class="s-h-red">🚨 Overdue (' + mgrOverdue.length + ')</h3>' + buildTableHtml(mgrOverdue, true);
  }
  if (mgrDueToday.length > 0) {
    block += '<h3 class="s-h-blue">📅 Due Today (' + mgrDueToday.length + ')</h3>' + buildTableHtml(mgrDueToday, false);
  }

  if (mgrMobile) {
    var waLink = buildWaLink(mgrOverdue, mgrDueToday, mgrMobile, name, formattedToday);
    block += '<a href="' + waLink + '" class="s-btn">📱 Send to ' + name + ' (+' + mgrMobile + ')</a>';
  } else {
    block += '<p style="color:#b45309;font-size:12px;margin-top:8px;">⚠ No mobile — add one in Managers sheet.</p>';
  }
  block += '</div>';
  return block;
}

// ============================================================
// Helper: build the shared table HTML (used everywhere) — CSS-class based
// ============================================================
function buildTableHtml(rows, isOverdue) {
  var cls = isOverdue ? 's-t s-t-red' : 's-t s-t-blue';
  var extraTh = isOverdue ? '<th>Days Late</th>' : '';
  var thead = '<thead><tr>' +
    '<th>Client</th><th>Mobile</th><th>Amount (₹)</th><th>Was/Is Due</th>' +
    extraTh +
    '<th>Remarks</th>' +
    '</tr></thead>';
  var body = '<tbody>' + rows.map(function(e) {
    var ovCell = isOverdue ? '<td class="s-ov">' + e.daysOverdue + '</td>' : '';
    return '<tr>' +
      '<td><strong>' + e.client + '</strong></td>' +
      '<td>' + e.mobile + '</td>' +
      '<td class="s-num">' + formatINR(e.amount) + '</td>' +
      '<td>' + e.nextCallDate + '</td>' +
      ovCell +
      '<td>' + (e.remarks || '-') + '</td>' +
      '</tr>';
  }).join('') + '</tbody>';
  return '<table class="' + cls + '">' + thead + body + '</table>';
}

// ============================================================
// Helper: build a wa.me deep-link with pre-filled message
// ============================================================
function buildWaLink(mgrOverdue, mgrDueToday, waNumber, audience, formattedToday) {
  var ovAmt = mgrOverdue.reduce(function(s, e) { return s + e.amount; }, 0);
  var dtAmt = mgrDueToday.reduce(function(s, e) { return s + e.amount; }, 0);
  var lines = [
    '📞 *Payment Follow-Up — ' + formattedToday + '*',
    (audience === 'Complete List' ? '📋 Full List' : '👤 ' + audience),
    '━━━━━━━━━━━━━━━━━━━━━━━',
    ''
  ];
  if (mgrOverdue.length > 0) {
    lines.push('🚨 *OVERDUE (' + mgrOverdue.length + ')*');
    mgrOverdue.forEach(function(e, i) {
      lines.push((i + 1) + '. *' + e.client + '*' + (e.company !== '-' ? ' | ' + e.company : ''));
      lines.push('   📞 ' + e.mobile + '   |   💰 ₹' + formatINR(e.amount));
      lines.push('   📅 Was due: ' + e.nextCallDate + '  (' + e.daysOverdue + ' day' + (e.daysOverdue === 1 ? '' : 's') + ' overdue)');
      if (e.remarks) lines.push('   📝 ' + e.remarks);
      lines.push('');
    });
    lines.push('Subtotal Overdue: ₹' + formatINR(ovAmt));
    lines.push('─────────────────────');
    lines.push('');
  }
  if (mgrDueToday.length > 0) {
    lines.push('📅 *DUE TODAY (' + mgrDueToday.length + ')*');
    mgrDueToday.forEach(function(e, i) {
      lines.push((i + 1) + '. *' + e.client + '*' + (e.company !== '-' ? ' | ' + e.company : ''));
      lines.push('   📞 ' + e.mobile + '   |   💰 ₹' + formatINR(e.amount));
      if (e.remarks) lines.push('   📝 ' + e.remarks);
      lines.push('');
    });
    lines.push('Subtotal Due Today: ₹' + formatINR(dtAmt));
    lines.push('─────────────────────');
    lines.push('');
  }
  lines.push('TOTAL TO COLLECT: ₹' + formatINR(ovAmt + dtAmt));
  return 'https://wa.me/' + waNumber + '?text=' + encodeURIComponent(lines.join('\n'));
}

function formatINR(n) {
  if (n === null || n === undefined || isNaN(n)) return '0';
  var v = Number(n);
  return v.toLocaleString('en-IN', { minimumFractionDigits: 2, maximumFractionDigits: 2 });
}

// TRIGGER SETUP: Install daily trigger at 9 AM
// ============================================================
function installDailyTrigger() {
  var triggers = ScriptApp.getProjectTriggers();
  triggers.forEach(function(trigger) {
    if (trigger.getHandlerFunction() === 'sendWhatsAppReminder') {
      ScriptApp.deleteTrigger(trigger);
    }
  });

  ScriptApp.newTrigger('sendWhatsAppReminder')
    .timeBased()
    .everyDays(1)
    .atHour(9)
    .create();

  return 'Daily reminder trigger installed! Reminders will be sent every day at 9 AM.';
}
